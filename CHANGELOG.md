# Changelog

## 0.1.0 — prepared, unpublished

- Bounded HTML document trees with read-only traversal, attribute filters,
  visible text/title extraction and incremental HTMLParser feeds.
- Strict CSS selector subset with scoped, deduplicated, source-order results.
- Incremental link/text collectors with explicit URL resolution and callback-only
  output, sharing the single-use lifecycle and resource limits.
- Bounded thread collection/iteration with input-order or ready-first results,
  original exceptions, queued cancellation and joined worker cleanup.
- Unicode-aware naming conventions with NFC normalization and acronym handling.
- Type annotations, MIT license, offline examples, three-platform CI and exact
  installed-distribution verification; Trusted Publishing workflow prepared.

HTML5 browser recovery, JavaScript, HTTP fetching, mutation/serialization,
model extraction, process/interpreter pools and asyncio helpers are future scope.
