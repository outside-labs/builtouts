# Builtouts

Building out Python's batteries.

Builtouts provides dependency-free interfaces and explicit conventions over
Python's builtins and standard library. The initial release is being prepared
for Python 3.14+, with HTML extraction, bounded thread concurrency, and naming
conventions. Modules are independently usable and do not modify Python globals.

See [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) for the selected contracts,
delivery tasks, release gate, and future opportunities.
